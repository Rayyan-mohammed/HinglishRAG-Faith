# Demo

Working demo for Objective O6: takes a Hinglish question, shows the generated answer with
each claim tagged supported / contradicted / unverifiable.

Started in A3 (skeleton: question in, answer out), finished in A4 (claim tags added).

Framework not chosen yet — pick whatever's fastest to wire to `src/pipeline.answer_question()`
(Streamlit, Gradio, or a notebook are all fine at this scale). Record the choice in
`docs/problems_and_decisions.md` once made.
